## Acceptance notes

CI/CD means test, build **and automatic deployment**, not image publication alone. Every workload listed above needs its own evidence even if workflows share templates. Go gateway services and contract compatibility checks are additional delivery obligations under #60. Secrets remain outside code.

Named rubric tools (including feature, inference, orchestration, IaC and observability products) illustrate capabilities. Selection remains deferred; document the equivalent capability and its evidence instead of silently dropping a requirement. Model quality on synthetic data cannot establish real-world fraud performance. Drift without labels measures distribution changes, not predictive accuracy.

The [architecture inventory](../architecture/payment-gateway.md#current-foundation) links the existing source and configuration. No target runtime capability is marked verified by this documentation change.
